# Sistema-de-Avalia-o-f-sica-
Sistema de avaliação física desenvolvido em JavaScript para praticar lógica de programação, estruturas condicionais, operadores lógicos, validação de dados e interação com o usuário. O projeto recebe informações do aluno, calcula o IMC, classifica sua condição física e apresenta recomendações personalizadas de acordo com regras predefinidas.
