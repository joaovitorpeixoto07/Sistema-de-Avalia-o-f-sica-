# 🏋️ FitSchool - Sistema de Avaliação Física

Projeto desenvolvido em JavaScript com o objetivo de praticar e aplicar conceitos fundamentais de lógica de programação.

## 📋 Sobre o projeto

O FitSchool é um sistema de avaliação física que recebe informações do usuário, como nome, idade, peso, altura, nível de atividade física e frequência semanal de exercícios.

A partir desses dados, o sistema realiza cálculos e aplica regras de negócio para classificar a condição física do aluno e apresentar uma orientação personalizada.

## 🚀 Funcionalidades

- Cadastro das informações do aluno
- Entrada de dados pelo usuário
- Validação das informações
- Cálculo do IMC
- Classificação da condição física
- Aplicação de regras utilizando `if`, `else if` e `else`
- Uso de operadores lógicos:
  - `&&` (E)
  - `||` (OU)
  - `!` (NÃO)
- Exibição de mensagens personalizadas

## 🧠 Conceitos praticados

Este projeto foi desenvolvido principalmente para estudar:

- Variáveis
- Tipos de dados
- Conversão de valores com `Number()`
- Estruturas condicionais
- Operadores relacionais
- Operadores lógicos
- Validação de dados
- Cálculos matemáticos
- Lógica de programação
- Interação com o usuário através de `prompt()` e `alert()`

## 📊 Classificação

O sistema utiliza regras de negócio para classificar o aluno em categorias como:

- 🏆 Excelente
- ⭐ Bom
- 🥉 Regular
- ⚠️ Atenção

Cada categoria possui uma mensagem de orientação de acordo com os resultados obtidos.
